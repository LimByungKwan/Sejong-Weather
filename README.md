# 세종, 오늘의 기온 — 오늘의 진짜 정보판

세종 대표 지점(36.4800, 127.2890)의 Open-Meteo 기상 모델 기반 현재 기온을 기록하고 비교하는 공개 정보판입니다. 관측소 직접 실측이나 일평균 기온이 아닙니다. 로그인·비밀키·개인 GPS를 사용하지 않습니다.

- 공개 결과: https://sejong-weather-daily.quannie70.chatgpt.site
- 합성 실패 시험: https://sejong-weather-daily.quannie70.chatgpt.site/replay
- 공개 소스 저장소: https://github.com/LimByungKwan/Sejong-Weather

## 화면과 저장

값·°C·출처·출처 기준 시각·조회 시각·Asia/Seoul을 표시합니다. 원자료와 서버 저장값, 화면값을 나란히 대조하고 날짜별 원자료를 펼쳐 볼 수 있습니다. 실제 저장 기온의 꺾은선 그래프는 날짜 간격을 반영하며 누락 날짜는 점선으로 연결합니다. 날짜 버튼으로 상세 시각을 확인할 수 있습니다.

서버 D1의 `record_date`가 기본키입니다. KST 조회 날짜로 저장하므로 같은 날 성공은 한 행을 갱신하고 다음 날 성공은 새 행을 추가합니다. 실패는 기존 정상 기록을 덮어쓰지 않습니다. 조회·저장 버튼을 누르지 않는 단순 페이지 새로고침은 저장값을 읽기만 합니다.

브라우저가 비밀키 없는 공개 원천을 직접 조회한 후 POST가 좌표·단위·유한 숫자·출처 시각의 최근성을 검증하여 저장합니다. 원자료는 `raw_json`에 저장합니다. 공개 쓰기 경로로, 원천 진위에 대한 암호학적 보증은 제공하지 않습니다.

공개 원천 호출 경로:

https://api.open-meteo.com/v1/forecast?latitude=36.4800&longitude=127.2890&current=temperature_2m&timezone=Asia%2FSeoul

## 실제 이틀 확인

2026-10-16 사용자 캡처에서 다음 두 실제 기록을 대조했습니다. 이것은 합성 fixture가 아닙니다.

| KST 조회 날짜 | 저장·표시 기온 | 출처 기준 시각 | 서버 조회 시각 |
| --- | --- | --- | --- |
| 2026-10-15 | 20.4°C | 2026-10-15T12:45:00+09:00 | 2026-10-15T03:46:44.331Z |
| 2026-10-16 | 21.6°C | 2026-10-16T12:30:00+09:00 | 2026-10-16T03:41:52.695Z |

두 기록 모두 원자료·저장값·화면값 및 출처 URL·단위·출처 시각의 일치를 확인했습니다. 계산은 최신 날짜 값 − 직전 날짜 값이며 **21.6 − 20.4 = +1.2°C**입니다. 소수점 오차는 6자리까지 정리합니다. 어제 기록이 없으면 ‘이전 기록 대비’로 표시합니다. 실제 DB는 소스 ZIP에 포함하지 않습니다. 공개 화면에서 저장된 원자료를 확인할 수 있습니다. 이후 같은 날 재조회하면 그날 값과 조회 시각은 갱신됩니다.

## 검증 범위

- Node 자동 검사 13개 통과: 다섯 실패·복구, 참조 adapter 일치, 17개 hash, 같은 날 중복과 다음 날짜, KST 자정, 실제/합성 쓰기 분리, 변화값·날짜 공백·단위 불일치.
- 현재 배포 빌드 통과. 사용자 캡처에서 실제 이틀 원자료 대조·변화값·그래프를 확인했습니다. 결과 URL은 사용자 시크릿 창에서 확인했습니다.
- 배포 소스 148개·배포 파일 88개·Git 7커밋을 검색한 초기 검사에서 비밀값 후보 0건을 확인했습니다. 2026-10-16 GitHub 업로드본 144개 파일·2커밋도 별도 검색하여 후보 0건을 확인했습니다. 패턴 검색은 모든 비밀값 부재의 보증이 아닙니다. 최종 소스 업로드 뒤 고정 URL의 무로그인 접근을 확인합니다.
- 개인정보 입력 기능이 없으며 도시 단위 공공 기상 자료와 합성 시험값만 사용합니다. 브라우저·네트워크 캡처에 개인 쿠키 등을 포함하지 마세요.

## 기술과 검사 실행

React 19, Vinext, Cloudflare Workers, Drizzle ORM, D1을 사용합니다. Node 22.13 이상과 pnpm이 필요합니다. 의존성을 설치한 환경에서:

```sh
node --test tests/replay.test.mjs tests/daily-comparison.test.mjs
pnpm build
```

공개 결과는 서버와 D1을 사용하는 Sites 배포입니다. GitHub는 소스 공개 용도이며 GitHub Pages 설정만으로 동일한 서버 저장 기능을 실행할 수 없습니다. `.openai/hosting.json`은 현재 Sites 배포 설정이며 별도 환경 재배포 시 해당 환경의 DB 바인딩과 스키마 적용이 필요합니다.
